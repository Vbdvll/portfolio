Mes Projets

Au cours de ma formation, j'ai dû mettre en place les projets ci-dessous et acquérir des compétences solides.

Projet de fin d'études – Geodaara

Conception d'un dispositif embarqué permettant le suivi en temps réel de personnes. Intégration d'un module GPS (Neo-6M) et d'une connectivité GSM (SIM800L), avec plateforme Django et carte Leaflet.js pour la visualisation en temps réel.

SOC – Détection & réponse automatisée

Architecture complète hébergée sur Azure : agents Wazuh, moteur de corrélation (10+ règles personnalisées), Active Response, et daemon IA (Gemini) pour le diagnostic contextuel et le blocage automatique des IP attaquantes.

Planification d'un lien Faisceau Hertzien

Conception d'une architecture multi-bonds (23/18 GHz) sous Aviat Design, méthode ITU-R P.530 : bilan de liaison, clairance de Fresnel et comparaison des modulations QPSK / 64-QAM / 256-QAM, pour le projet SenBank.

Cluster de stockage distribué Ceph

Déploiement d'un cluster Ceph (Squid v19) sur 3 instances AWS EC2, orchestration via cephadm et Podman, configuration du quorum MON et des Security Groups AWS.

Déploiement d'applications avec Docker

Conteneurisation d'une application (images, Dockerfile, volumes, réseaux Docker) et présentation pédagogique du cycle de déploiement avec démonstration live.

Déploiement OpenStack via DevStack

Mise en place d'un environnement cloud privé complet (Nova, Neutron, Glance…) sur AWS EC2, avec personnalisation d'une stack LAMP + PHP sur l'infrastructure.

Bot Telegram – Automatisation n8n

Bot d'apprentissage de vocabulaire déployé sur AWS EC2 : workflows n8n, PostgreSQL, Nginx, Cloudflare, synthèse vocale Azure TTS et IA Gemini.

Tests d'intrusion – Metasploitable

Reconnaissance et scan de vulnérabilités (Nmap) sur machine cible Metasploitable, exploitation de failles avec Metasploit et analyse des vecteurs d'attaque.

Administration système & infrastructure réseau

Installation d'un serveur web Apache sur Linux, configuration d'un serveur DNS et d'Asterisk pour la téléphonie IP, partage de fichiers avec Samba et centralisation des logs avec rsyslog.

Sécurisation réseau – Pare-feu Linux

Mise en place d'un pare-feu avec IPTables, filtrage, NAT et routage.

Environnement Windows Server 2019

Déploiement d'un contrôleur de domaine, gestion des utilisateurs, GPO, DNS et DHCP.

Routage et segmentation réseau

VLAN, inter-VLAN et routes statiques sur équipements Cisco lors des séances de travaux pratiques.

Dictionnaire Français-Wolof (Java)

Application Java permettant la recherche et la traduction de mots du français vers le wolof et inversement. Conçu avec une base de données intégrée et une interface simple pour un accès rapide aux définitions.
